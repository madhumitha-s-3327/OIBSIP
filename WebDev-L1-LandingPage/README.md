# 🚀 Mithu's Tech Lab - Landing Page

A sleek, responsive, and modern landing page template designed with CSS Glassmorphism effects and a dark theme palette.

---

## ✨ Features

* **Glassmorphism Design:** Modern translucent UI elements with blur effects.
* **Fully Responsive:** Smooth layout adjustments across mobile, tablet, and desktop views.
* **Dark Theme:** High-contrast dark aesthetic tailored for modern web apps.
* **Interactive Components:** Hover animations, sticky navigation, and styled dynamic buttons.
* **Clean Code Structure:** W3C compliant CSS without vendor-prefix warnings or syntax errors.

---

## 🛠️ Built With

* **HTML5** - Page structure and semantics
* **CSS3** - Custom properties (variables), Flexbox, CSS Grid, and Glassmorphism effects
* **Google Fonts** - Poppins font family
* **Font Awesome** - Modern vector icons
