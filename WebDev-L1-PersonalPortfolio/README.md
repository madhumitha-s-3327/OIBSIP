# 🌟 Personal Portfolio Website

A clean, responsive, and glassmorphism-styled personal portfolio built using **HTML5, CSS3, and JavaScript**. Designed as part of the **Oasis Infobyte (OIBSIP)** Web Development Internship (Task 2).

---

## ✨ Key Code Features

- **🎨 Glassmorphism & Custom Properties:** CSS variables (`:root`) with dynamic `backdrop-filter: blur()` effects for a modern pastel look.
- **⚡ Custom JS Typing Animation:** Pure Vanilla JavaScript typing & deleting loop implemented directly inside the HTML via `<script>` tag.
- **📱 Responsive Layout:** Structured using **CSS Flexbox** and **CSS Grid** to ensure seamless layout adjustment across mobile, tablet, and desktop screens.
- **🎯 Dynamic UX Sections:** Dedicated UX Breakdown cards showcasing problem-solution mapping for projects.
- **📩 Contact Integration:** Interactive HTML form connected via **Formspree API** for direct inbox notifications.
- **👩‍🎓 Font Awesome Vector Avatars:** Scalable SVG icon avatar for clean, crisp rendering without broken image issues.

---

## 🛠️ Tech Stack & Code Logic

| Language / Tool | Implementation Purpose |
| :--- | :--- |
| **HTML5** | Semantic layout structure (`<nav>`, `<section>`, `<footer>`, `<form>`) |
| **CSS3** | Custom Variables, Animations (`@keyframes bounce`), Flexbox & Grid layouts |
| **JavaScript (ES6)** | DOM manipulation (`document.querySelector`) for hero typing effect |
| **Font Awesome 6** | Scalable vector icons for technical skills and social profiles |
